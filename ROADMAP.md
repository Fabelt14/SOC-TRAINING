# SOC-TRAINING Roadmap

## Overview
This roadmap defines the 6-month execution path for SOC training. Each week produces hands-on artifacts for a professional portfolio.

## Phase 1: Foundations (Week 1-4)
- SOC fundamentals
- Linux log analysis
- Network traffic fundamentals
- Wireshark deep dive

## Phase 2: Core Analyst Skills (Week 5-10)
- tcpdump mastery
- Windows event logs
- SIEM basics
- Splunk and ELK labs
- Threat intelligence fundamentals

## Phase 3: Detection & Hunting (Week 11-16)
- IOC hunting
- Detection engineering
- Sigma rules
- YARA rules
- Malware triage
- Phishing analysis

## Phase 4: Advanced Blue Team (Week 17-22)
- Digital forensics
- Incident response
- Active Directory security
- MITRE ATT&CK mapping
- SOC case studies
- Blue team CTFs

## Phase 5: Capstone (Week 23-24)
- Full SOC simulation
- Realistic incident response scenarios
- Portfolio finalization

## Outcome
A complete SOC portfolio with:
- Detection rules
- Investigation reports
- Dashboards
- Threat hunting reports
- Incident response documentation
