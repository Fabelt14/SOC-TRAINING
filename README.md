# SOC-TRAINING

A 6-month hands-on SOC (Security Operations Center) training program designed to take you from beginner to job-ready Blue Team analyst through real-world labs, simulations, and portfolio-building exercises.

## Objective
Build practical SOC capability through structured weekly labs covering:

- Network traffic analysis
- Log analysis (Linux, Windows)
- SIEM operations (Splunk, ELK)
- Threat intelligence and IOC hunting
- Detection engineering (Sigma, YARA)
- Incident response and forensics
- Mock SOC shift simulation

This repository is not theory-heavy. It is execution-heavy.

## Structure
Each week contains:

- Lab objectives
- Step-by-step exercises
- Attack and defense scenarios
- Expected artifacts (reports, rules, dashboards)
- Portfolio outputs

By the end of this program, you will have:

- SOC-ready portfolio
- Detection rules (Sigma/YARA)
- SIEM dashboards
- Incident reports

- Practical SOC workflow experience

## Philosophy
You are not studying cybersecurity. You are operating like a SOC analyst in training.
